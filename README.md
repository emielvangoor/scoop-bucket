# emielvangoor/scoop-bucket

[Scoop](https://scoop.sh) manifests for [paseo-tui](https://github.com/emielvangoor/paseo-tui), the
keyboard-first terminal client for [Paseo](https://github.com/getpaseo/paseo). Windows x86_64 and ARM64.

```powershell
scoop bucket add emielvangoor https://github.com/emielvangoor/scoop-bucket
scoop install emielvangoor/paseo-tui
scoop update paseo-tui
```

The manifest is updated automatically by paseo-tui's release workflow, so please don't edit it by hand.
Report problems in the [paseo-tui issues](https://github.com/emielvangoor/paseo-tui/issues).
